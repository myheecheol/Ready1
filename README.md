# 주간학습 안내 웹앱

한글(HWP)로 만들던 주간학습안내를 웹앱으로 옮긴 것입니다. 설치 없이 브라우저에서 열리고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 기능
- **문서 모양 그대로**: 교시·1~6교시·TO DO 열, 하루 3줄(교과 / 단원 및 주제 / 비고), 칸 합치기, 박스 강조, 학생 체크표와 MEMO
- **과목과 색상**: 과목 추가·삭제·순서 변경, 색을 바꾸면 모든 주에 반영
- **템플릿**: 여러 템플릿 저장, ★ 기본 템플릿으로 새 주 자동 생성, 짝수/홀수 주 다른 과목, 주별 개별 수정, 지난주 복사, 이 주를 템플릿으로 저장
- **날짜·휴일 자동**: 앱을 열면 이번 주, 학기 시작일 기준 주차 계산, 2026–2028 공휴일·대체공휴일 내장, 재량휴업일·방학 직접 등록
- **휴대폰**: 요일별 카드 보기, 오프라인 사용(PWA)
- **저장**: 자동 저장, JSON 내보내기/가져오기, 인쇄(A4 한 장)

## 파일
- `app/weekly.html` — 앱 본문(여기를 고칩니다)
- `index.html` — `npm run build`로 만드는 배포용 파일
- `manifest.webmanifest`, `sw.js`, `icon*` — 홈 화면 추가·오프라인용

## 실행과 배포
```bash
npm run build   # index.html 생성
npm start       # http://localhost:5173 에서 확인
```
GitHub Pages: 저장소 Settings → Pages → Branch를 이 브랜치의 `/ (root)`로 지정하면 `index.html`이 바로 배포됩니다.
