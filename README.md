# 주간학습 안내 웹앱

한글(HWP)로 만들던 주간학습안내를 웹앱으로 옮긴 것입니다. 설치 없이 브라우저에서 열리고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 기능
- **문서 모양 그대로**: 교시·1~6교시·TO DO 열, 하루 3줄(교과 / 단원 및 주제 / 비고), 칸 합치기, 박스 강조, 학생 체크표와 MEMO
- **과목과 색상**: 과목 추가·삭제·순서 변경, 색을 바꾸면 모든 주에 반영
- **템플릿**: 여러 템플릿 저장, ★ 기본 템플릿으로 새 주 자동 생성, 짝수/홀수 주 다른 과목, 주별 개별 수정, 지난주 복사, 이 주를 템플릿으로 저장
- **수업 유형**: 색깔별 유형(교과·강사·담임 수업)과 단원 및 주제 기본값, 홀수 주 과목·주제 교대
- **학생 표**: 칸마다 체크리스트/메모 전환, 요일별 출결(결석·지각·조퇴·사유), 출결 탭에서 월별 정리
- **시수**: 주별 과목 시수, 시수 탭에서 학기별 과목 시수·목표 대비 차이
- **날짜·휴일 자동**: 앱을 열면 이번 주, 학기 시작일 기준 주차 계산, 2026–2028 공휴일·대체공휴일 내장, 재량휴업일·방학 직접 등록
- **휴대폰**: 요일별 카드 보기, 오프라인 사용(PWA)
- **저장**: 자동 저장, JSON 내보내기/가져오기, 인쇄(A4 한 장)

## 기기 간 동기화 (구글 시트 · Apps Script)
휴대폰·학교 컴퓨터·노트북에서 같은 내용을 쓰려면 내 구글 계정의 스프레드시트에 저장하도록 연결해요. 설정 화면에 같은 안내가 있어요.

1. 앱 **설정 → 기기 간 동기화**에서 동기화 비밀번호를 정하고 **코드 복사**를 눌러요.
2. [새 구글 스프레드시트](https://sheets.new)에서 **확장 프로그램 → Apps Script**를 열고, 원래 코드를 지운 뒤 붙여넣고 저장해요.
3. **배포 → 새 배포 → 웹 앱**, 실행: **나**, 액세스 권한: **모든 사용자** → 배포 → 권한 허용.
4. 나온 웹 앱 URL(`…/exec`)을 앱에 붙여넣고 **연결**.
5. **다른 기기 연결하기**의 QR이나 링크를 휴대폰·다른 컴퓨터에서 열면 바로 연결돼요.

- 서버 코드: `sync/apps-script.gs` (빌드할 때 앱 안에 들어가서 설정 화면의 **코드 복사**로 나와요)
- 데이터는 스프레드시트의 `data` 시트에 문서(설정 1개 + 주마다 1개) 단위로 저장돼요.
- 같은 주를 두 기기에서 동시에 고치면 나중에 저장한 쪽이 남아요.
- Apps Script 코드를 고쳤다면 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영돼요.

## 학생·학부모 화면 (`student/`)
교사용 앱과 같은 구글 시트를 써요. 교사 앱이 저장할 때마다 학생용 게시본(`pub`)을 함께 올리고, 서버(Apps Script)는 **이번 주와 다음 주**만 학생 화면에 내보내요.

- 보이는 것: 시간표(과목·단원 및 주제·비고), 체크리스트 칸, 반 친구들의 체크 현황
- 안 보이는 것: MEMO, TO DO, 출결, 메모 칸, 비밀번호, 다다음 주부터의 시간표
- 체크: 학생이 번호 + 비밀번호 4자리로 들어가 자기 것만 체크·해제. 선생님이 **확정**한 항목은 서버가 막아요. 비밀번호 5번 틀리면 10분 잠금
- 체크 1건 = 시트의 행 1개(`c-주-칸-학생`)라서 선생님과 학생이 동시에 눌러도 서로 덮어쓰지 않아요 (check-list의 '제출 1건 = 파일 1개' 방식)
- 설정: 교사 앱 **설정 → 학생·학부모 화면**에서 비밀번호 만들기, 링크·QR 받기
- 체크리스트 항목: 교사 앱 학생 표에서 칸 종류를 ✓ 체크리스트로 바꾸고 제목을 쓰면 돼요. 칸 설정에서 마감일·확정·안 한 학생 복사

## 파일
- `app/weekly.html` — 앱 본문(여기를 고칩니다)
- `index.html` — `npm run build`로 만드는 배포용 파일
- `sync/apps-script.gs` — 구글 시트 동기화 + 학생 화면용 Apps Script
- `student/index.html` — 학생·학부모 화면
- `manifest.webmanifest`, `sw.js`, `icon*` — 홈 화면 추가·오프라인용

## 실행과 배포
```bash
npm run build   # index.html 생성
npm start       # http://localhost:5173 에서 확인
```
GitHub Pages: 저장소 Settings → Pages → Branch를 이 브랜치의 `/ (root)`로 지정하면 `index.html`이 바로 배포됩니다.
